PROJECT NAME: To-Do List Application

INTERNSHIP TASK: Task 1

PROGRAMMING LANGUAGE: Python

TOOLS USED: VS Code, Python

PROJECT DESCRIPTION:
This project is a simple To-Do List application developed using Python. It helps users manage their daily tasks.

FEATURES:

1. Add Task
2. Show Tasks
3. Complete Task
4. Delete Task
5. Save Tasks using JSON

HOW TO RUN:

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Type: python todo_app.py
5. Press Enter.
